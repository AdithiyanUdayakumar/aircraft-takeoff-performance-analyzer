#project statement

##Problem statement

Aircraft takeoff performance can be influenced by different aircraft and runway conditions such as aircraft mass,engine thrust,wing area,takeoff speed,air density and runway length.
The purpose of this project is to develop a simple python based program that uses selected aircraft,aerodynamic and runway parameters to calculate takeoff performance and determine whether the available runway is sufficient.
The project is designed as an educational model to demonstrate how python programming concepts can be applied to an aerospace engineering problem.

##scope

The project focuses on estimating aircraft takeoff performance using:
-aircraft mass
-engine thrust
-wing area 
-lift coefficient 
-drag coefficient
-takeoff speed
-air density
-runway length 
-runway slope
-wind speed

The program calculates dynamic pressure,lift,drag,net force,acceleration and required takeoff distance.

##target users

the project is mainly intended for:
-aerospace engineering students
-students learning python
-students interested in basic aerodynamics
-engineers interested in basic aircraft performance calculations

##High level features

-accepts aircraft and runway inputs
-calculates dynamic pressure
-calculates net force
-calculates lift and drag
-calculates aircraft acceleration
-calculates required takeoff distance
-calculates runway safety margins
-performs basic input validations
-displays the calculated results through command Line 

##expected outcomes

a simple python based aerospacce related programbthat demostrates the relationship between selected aircraft,aerodynamic and runway parameters and provides an educational estimation.
